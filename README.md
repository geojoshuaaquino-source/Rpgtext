# RPG: Endless Descent

A mobile endless-run roguelite RPG built with Kotlin and Jetpack Compose.

## Core loop

- Start every run with a randomized build.
- Receive a random quantity of abilities, with rarity from Common to Mythical.
- Skills and starting equipment are randomized each run.
- Defeat increasingly powerful enemies.
- Collect randomized equipment and abilities.
- Build a stronger character during the run.
- There is no final boss or ending encounter: the run continues until the character dies.
- Death starts a completely new randomized run.

## Build

Android project using Kotlin, Jetpack Compose, Material 3, and Android SDK 35.

The repository includes a GitHub Actions workflow that builds the debug APK on pushes and pull requests.
